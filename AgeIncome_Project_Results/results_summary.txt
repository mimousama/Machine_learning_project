Machine-learning type and objective
K-Means is an unsupervised learning algorithm. For this exercise, the rows are treated as unlabeled: Age and Income are used to find homogeneous groups of people. There is no known target label. A supervised X_train/X_test/y_train/y_test split is therefore not normally required; clustering evaluates structure in the data rather than predicting a held-out labeled target.

Interpretation and limitations
Cluster numbers are arbitrary identifiers, not rankings. Compare the mean Age and Income values to describe each group. K-Means is distance-based and sensitive to scaling, outliers, and the chosen K. Because there are no reference labels, K-Means does not directly provide accuracy or a confusion matrix; no accuracy value is invented.
Recommendations: describe each segment using its original-unit centroid and size; compare the K=3 and selected-K profiles; and validate whether the segments are useful for the project's real question before making decisions about people.
